# Copiloto (Fabric 1.21.4)
- V: dice cuantas pociones de curacion te quedan y que piezas de armadura estan bajas.
- H: activa/desactiva marcar monstruos hostiles visibles en rojo (nunca jugadores).
- Avisos automaticos: al gastar una pocion (si quedan pocas), durabilidad al 50/25/10%, vida baja.
- Config: config/copiloto.json
Las voces se generan en el build con espeak-ng + ffmpeg.
